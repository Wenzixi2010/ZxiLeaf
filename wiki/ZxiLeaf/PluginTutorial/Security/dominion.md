# Dominion 圈地教程

## 🔍 什么是 [Dominion](https://www.minebbs.com/resources/dominion-res-folia.7933/)？

Dominion 是一款现代、高版本的领地保护插件，你可以将它看作一个更强大的“圈地系统”，用于保护你建造的建筑和物品不被其他玩家破坏或偷走。

---

## 📝 创建你的第一块领地

### 方法一：手动圈地（推荐）

你需要使用圈地工具（默认为**箭矢**）来选定一个长方体区域。

1. **选择第一个点**：手持箭矢，对你要圈领地的**第一个角落**（比如最西北角的地面）**左键点击**。
2. **选择第二个点**：然后跑到**对角线的另一个角落**（比如最东南角的上空），**右键点击**。
3. **创建领地**：选好后，在聊天栏输入以下指令并回车：`/dominion create <你的领地名称>`
例如：`/dominion create mybase`

> ⚠️ **注意**：领地名称不能和其他领地重复，且只建议包含英文字母、数字、下划线和短横线。

---

### 方法二：自动创建（新手友好）

如果你嫌手动选点麻烦，可以使用自动创建功能，系统会以你为中心自动生成一块领地。

1. 输入 `/dominion` 打开主菜单。
2. 点击【**创建领地**】按钮。
3. 根据提示在聊天栏输入你想要的领地名称即可。

---

## ⚙️ 管理你的领地

成功创建领地后，你可以通过领地管理界面进行各种个性化设置。

| 操作 | 说明 |
| :--- | :--- |
| **打开管理界面** | 站在你的领地内，输入 `/dominion` 或 `/dom` 即可打开菜单 |
| **设置传送点** | 站在你想设为传送点的位置，在管理界面点击【**设置传送**】。以后别人就可以用 `/dominion tp <领地名称>` 直接传送到这里 |
| **设置进入消息** | 在管理界面点击【**进入提示**】，为领地设置欢迎语 |
| **设置离开消息** | 在管理界面点击【**离开提示**】，为领地设置告别语 |

### 消息占位符

在设置进入/离开消息时，你可以使用以下特殊占位符让消息更生动：

| 占位符 | 说明 |
| :--- | :--- |
| `{OWNER}` | 领地所有者的名字 |
| `{DOM}` | 领地名称 |
| `{PLAYER}` | 进入/离开领地的玩家名字 |

**示例**：`欢迎 {PLAYER} 来到 {OWNER} 的领地 {DOM}！`

## 🛠️ 常用指令一览

| 指令 | 说明 |
| :--- | :--- |
| `/dominion create <名称>` | 创建名为 `<名称>` 的领地 |
| `/dominion tp <名称>` | 传送到名为 `<名称>` 的领地 |
| `/dominion` 或 `/dom` | 打开领地主菜单，进行高级管理 |
| `/dominion info` | 查询当前所在领地的信息 |
| `/dominion delete <名称>` | 删除名为 `<名称>` 的领地 |
| `/dominion list` | 列出你拥有的所有领地 |

## 📚 进阶小贴士

### 管理领地成员

在领地管理界面，你可以添加或删除其他玩家，并为他们设置不同的权限（如建造、使用物品等）。

**Q：我忘记领地名称了怎么办？**  
A：输入 `/dominion list` 可以查看你拥有的所有领地列表。

**Q: 如何查看领地大小？**
A：使用线左键领地范围内的任意方块，将显示领地边界与领地信息。

**Q: 领地有数量上限吗？**
A：每个玩家最多可以设置10个领地（3个维度世界的领地数量加在一起）。
