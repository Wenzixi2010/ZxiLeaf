# 常用指令

| 指令 | 说明 | 补充 |
| --- | --- | --- |
| `!!here` | 共享自己的当前位置 | |
| `!!vris 玩家名` | 查询指定玩家的当前位置 |  |
| `/tpa 玩家名` | 向目标玩家发起传送请求 | 需对方同意 |
| `/tphere 玩家名` | 将目标玩家传送到你的位置 | 需对方同意 |
| `/sethome 名字` | 设置一个传送点（家） | 可设置多个，用不同名字区分 |
| `/homes` | 查看已设置的所有家 |  |
| `/home 名字` | 传送到指定的家 |  |
| `/delhome 名字` | 删除指定的家 |  |
| `/back` | 回到上一次传送或死亡前的位置 |  |
| `/warp 区域名字` | 传送到服务器内的公共设施区域 | 直接发送/warp可查看可传送区域列表 |
| `/sit` 或 `/gsit` 或 `右键视角指向方块`| 坐在玩家当前站立方块上 |  |
| `/lay` 或 `/glay` | 躺在玩家当前站立方块上 |  |
| `/bellyflop` 或 `/gbellyflop` | 趴在玩家当前站立方块上 |  |
| `/spin` 或 `/gspin` | 在玩家当前站立方块上转圈 |  |
| `/crawl` 或 `/gcrawl` | 在地上爬行 | |

:::note

更多指令等待玩家在游戏中发掘

:::
